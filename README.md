# CORE — Fall Study Desk

Personal exam-prep site for I-Core + Business Ethics.

## Courses

- I-Core Finance
- I-Core Marketing
- I-Core Leadership
- I-Core Operations
- Business Ethics

Each course has **condensed notes**, **flashcards**, and **quizzes**. Content starts empty and gets filled as you upload notes/slides in chat.

## Develop

```bash
npm install
npm run dev
```

## Content updates

Course content lives in `src/data/courses.ts`. When you send materials, that file (and related study data) is what gets updated.
