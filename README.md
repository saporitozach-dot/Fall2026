# CORE — Fall Study Desk

Personal exam-prep site for I-Core + Business Ethics.

**Live site:** https://saporitozach-dot.github.io/Fall2026/

## Courses

- I-Core Finance *(Class 1 TVM live)*
- I-Core Marketing
- I-Core Leadership
- I-Core Operations
- Business Ethics

Each course has **condensed notes**, **flashcards**, and **quizzes**. Content starts empty and gets filled as you upload notes/slides in chat.

## Develop

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Publishes to GitHub Pages at the live URL above.

## Content updates

Course content lives under `src/data/` (e.g. `finance.ts`). When you send materials, those files are what get updated.
